# 人类 XR：独立头部位姿与身体朝向估计

## 目标

头显位置和完整四元数都参与驱动 Avatar，不再把头显 yaw 直接等同于身体 yaw。
用双手的全局变化辅助判断身体是否跟着转动，同时保留已修复的 palm-v1 手掌朝向。
这只是头/双手三点驱动的姿态估计，不是胸部、腰部、膝盖的真实追踪数据。

## 采集端估计

`static/xr/xr-body-tracking.js` 的 `BodyTracker`：

1. 初次进入 XR，用头显朝向初始化身体朝向、用初始头高建立校准；建议入场时自然站立或坐好、面朝身体正前方。
2. 最近约 0.15–0.65 秒内，比较头部水平转动、左/右手连线的水平转动，以及两只手各自的世界旋转。
3. 双手连线转动方向/幅度与头部相符，并且两只手旋转也一致，才确认身体转动。
4. 头部转动、双手位置稳定时保持身体 yaw；只转手腕、只动一只手、双手交叉时不触发身体跟转。
5. 阈值和短暂置信度累积抑制追踪噪声；比较相对角度并绕回 ±π，避免越过 180° 时方向跳变。
6. 双手丢失时保持身体方向，只有头/身体偏角过大才缓慢跟随，避免突然扭转。重新接入双手后丢弃旧的判断窗口。
7. 头部和双手一起平移时移动身体锚点；头部位置变化而双手稳定时优先保留身体锚点、让上身倾斜。
8. 水平倾斜超过约 30cm 时允许身体移动，避免用户走远后 Avatar 下半身被留在原地。长暂停或参考空间突变后重新校准。

身体转动不等于简单比较“手掌旋转”：双手连线的转动也必须成立，避免将翻掌误判为转身。
头部保持全局朝向而双手做独立动作等情形仍可能有歧义，不能仅凭三点数据可靠还原所有身体动作。

## 网络格式（不改二进制协议 v3）

沿用 `p/yaw/pitch/hands`，`p` 仍是头显的世界位置，`yaw/pitch` 仍是头显朝向。
额外通过小状态携带完整头部旋转和估计的身体锚点：

```json
{
  "p": [0, 1.7, 0], "yaw": 0, "pitch": 0,
  "state": {
    "handOrientation": "palm-v1", "handSample": 42,
    "xr": {
      "v": 1,
      "p": [0, 1.7, 0],
      "q": [0, 0, 0, 1],
      "b": [0, 0, 0],
      "h": 1.7
    }
  }
}
```

- `xr.q`：完整头显世界四元数 `[x,y,z,w]`，包括 yaw/pitch/roll。
- `xr.b`：`[bodyYaw, bodyAnchorX, bodyAnchorZ]`，角度弧度，位置米。
- `xr.h`：本次 XR 会话的初始头高，不随每帧低头/下蹲更新。
- `xr.p`：用于判断该 state 是否与当前 p/yaw/pitch 同一帧；远距离 LOD 不下发 state 时不能把旧身体锚点继续套到新的世界位置上。
- 小数保留五位；格式有回归测试确保最坏数值也在 state 二进制块 255 字节内。
- `handSample` 随新采样递增，让元数据在 presence 合并窗口后仍有机会重复下发。

没有该 state 的旧客户端仍用原来的 yaw/pitch 路径。Agent 的 bones/animation 不使用人类估计。
**采集端和观看端都需要刷新并重新进入 XR**。

## 渲染端骨骼驱动

`static/xr/xr-avatars.js`：

- 身体 root 使用独立的 bodyYaw；保留人类现有的 180° 模型朝向修正。
- 完整头显四元数转换到模型 head 骨骼的绑定坐标系；头部朝向是世界姿态，不能再次叠加身体旋转。
- 一部分转动分配给 neck；spine/chest/upperChest/neck 的有界 CCD 用于头部位置倾斜。
- 高度映射使用固定初始头高，将下蹲/起身位移反映到骨盆；补偿腿部 IK 尽量保持脚的落点和方向。
- 先更新头/躯干和肩部，再解算手臂，保证头部侧倾不会破坏已对齐的手掌世界方向。
- 在骨骼可达范围内跟随，不拉长骨骼；幅度过大时会有残差，不能承诺所有深蹲姿态都精确复现。
- 显式骨骼/动画占用相关骨骼时让路；CCD 每步仅更新变动的 normalized 子树，不重复遍历整个模型。

## 验证

浏览器回归覆盖头动手不动、头/双手共同转、只转手腕、单手动作、慢速转身、跨越 ±π、
整体平移与独立头部倾斜、追踪丢失、真实 VRM0 模型及 VRM1 测试模型的原始网格骨骼、
头部 roll/pitch/yaw 与位置、脚部落点和旋转、手掌方向不退化，以及远距离陈旧 state 回退。
所有判断都是模拟输入/模型回归；实际 XR 设备效果仍需要用户上机验证。
