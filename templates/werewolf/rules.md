【狼人杀 9 人局 · 屠边】
阵容：3 狼人 + 预言家 + 女巫 + 猎人 + 3 平民。
胜负：狼人杀光全部神职或全部平民 → 狼胜；狼人全部出局 → 好人胜。

流程（由 Room Agent 裁判主持，裁判脚本全自动执行）：
1. 开局：裁判广播规则与座位表（N号=用户名），全员禁言，私聊逐人发角色卡，收到后回复「收到」。
2. 每夜：天黑闭眼。狼人在 #wolves 群商议后私报裁判「刀 N」（同伴与裁判互见）；预言家私报「查 N」，裁判私聊回「【查验结果】N号是【狼人/好人】」；女巫收「【用药】今晚 N号被刀」，私报「救 / 毒 N / 不用」（每晚限一瓶，不可自救）。
3. 每个白天：公布死讯（不公布死因与身份）→ 首夜死者有遗言 → 依次公开发言 → 全员公开投票「投票 N / 弃票」，唯一最高票放逐（平票 PK 后再投）；猎人出局可私报裁判「枪 N / 不开」带走一人（被女巫毒死的猎人不能开枪）。
4. 结束：广播胜负与全员身份复盘，删除全部私聊规则与群组，恢复全员发言。

私报协议（玩家 → 裁判，@@裁判 私聊）：
收到 · 刀 N · 查 N · 救 · 毒 N · 不用 · 枪 N · 不开。

缺省规则（掉线/超时不等人）：
投票未交=弃票；狼刀超时按多数提议裁定（平票或无人提议=空刀，平安夜）；神职超时=放弃技能；发言超时=跳过；连续 3 个夜昼周期无任何死亡与放逐=判平局收场；广播/cue 失败自动重试。

纪律：公开频道永不出现秘密（角色/刀口/验人结果）；秘密只走私聊；夜晚除狼队群聊外玩家互聊一律被服务器拒绝。
